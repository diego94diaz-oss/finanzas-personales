# Roadmap — Finanzas Personales

## Prioridad alta

- Mantener el repositorio libre de datos financieros reales.
- Agregar flujo explícito de importación/exportación cifrada.
- Separar código, datos de ejemplo y datos privados.
- Agregar pruebas manuales documentadas para desbloqueo, respaldo, importación y borrado.

## Prioridad media

- Añadir archivo `datos_ejemplo.js` con datos ficticios para demo pública.
- Agregar validaciones de JSON antes de importar respaldos.
- Mejorar mensajes de error al abrir la app sin datos publicados.

## Prioridad baja

- Migrar a estructura modular (`src/`, `assets/`) si el HTML crece demasiado.
- Evaluar una PWA offline instalable.
